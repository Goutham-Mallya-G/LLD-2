# Main Menu

1. Display All Employees
2. Filter and Update Employee Details
3. Manager Operations
4. Exit

---

# Model 1 – Display All Employees

When the user selects this option:

* Display all employee details.

---

# Model 2 – Filter and Update Employee Details

## Step 1 – Apply Filters

### Numeric Filter Operations

| Operations   |
| ------------ |
| Equal        |
| Not Equal    |
| Greater Than |
| Less Than    |

### String Filter Operations

| Operations    |
| ------------- |
| Equal         |
| Not Equal     |
| Contains      |
| Not Contains  |
| Starting With |
| Ending With   |

### Filtering Rules

* After applying one filter:

  * Display filtered employees.
  * Ask the user whether they want to continue filtering.
* If yes:

  * Apply the next filter only on the already filtered list.

---

## Step 2 – Update Employee Details

After filtering:

* Allow the user to update employee details.

### Steps

1. Choose employee by ID.
2. Select field to update.
3. Enter new value.
4. Display updated employee details.

### Fields Allowed for Update

* Name
* Age
* Department
* Designation
* Reporting To

---

# Model 3 – Manager Operations

## Feature 1 – Display Employees Under Manager

* Allow the user to enter a manager name.
* Display all employees reporting under that manager.

---

## Feature 2 – Promote Employee

* Allow promotion of employees by updating their designation.

### Steps

1. Enter employee ID.
2. Enter new designation.
3. Update employee designation.
4. Display updated employee details.

---

# Technical Requirements

* Use Java console application.
* Use Object-Oriented Programming concepts.
* Use classes and objects.
* Use encapsulation with getters and setters.
* Use ArrayList to store employees.
* Use menu-driven programming.
* Implement filtering using loops and conditions.
* Keep employee data hardcoded.
* Follow proper modular programming practices.
